训练集多构象能否被采样？决定因素是「随机潜变量解码器 + 似然目标」，而非离散 vs 连续

ProFOLD2 多构象扩展 · 聚焦"同一序列在训练集有多个构象，能否采样出来" · 文献调研 + 机制分析 2026-11-21

条件信号：仅 target sequence（无 MSA） 系综 / MD 数据：暂不考虑 目标：训练集多模可采样性（非泛化到未见构象） 解码器：保留 torsion-frame StructureModule
核心结论
  • 确定性 StructureModule 数学上不可能。无 MSA 时 trunk 对相同 seq 产出相同表示，angles/frames 是其确定性函数 → 相同输入唯一输出；FAPE/MSE 对"同输入多 GT"的最优解是均值（常不可物理）。无论训练集多少构象都只吐一个 —— 这是 AF2"即使训练集也采不出"的结构性根因。
  • AF3 diffusion 有随机性但塌缩。trunk 条件表示对多构象序列学到混合态，去噪训练偏高密度区 → mode collapse（双态恢复 ~20–23%，Peng 2025）。
  • 三要素缺一不可：① 随机/潜变量解码器（打破唯一输出）；② 保多模似然目标（NLL，而非 MSE-to-mean）；③ 区分 mode 的索引（离散 code / 潜变量 z / 噪声）——multiplicity 必须完全由解码器潜变量承载。
  • 离散似然生成对"训练集多模"最直接：categorical NLL 不平均多峰，离散 code 显式索引 basin，训练集 mode 有清晰概率质量 → 温度/top-k 采样即可采出。比连续扩散更不易插值出混合态。

最小可验证实验（无需系综 / MD）

选案例：取一小批训练集里同序列多构象的案例（蛋白 fold-switcher / apo-holo，RNA 多态）。
加离散生成头：最轻量直接把 torsion 分 bin 预测 categorical 分布（或先训 frame→code 的 VQ-VAE tokenizer）；trunk 表示不动或端到端用 NLL 微调。
似然训练：用 categorical NLL 在多模案例上训练。关键：别用 FAPE-to-single-GT，否则又平均塌缩。
评测 mode recall：采样 N 次，能否覆盖训练集那几个构象（TM-score / RMSD 聚类匹配）。
等数据对照：确定性头（应只出一个）vs 连续扩散头（看是否塌缩）vs 离散头 —— 隔离"离散 vs 连续"这一个变量。
为什么离散特别适合你的 torsion 解码器 + RNA：RNA 糖环 pucker（C2'/C3'-endo）、backbone suite rotamer、χ（anti/syn），蛋白 χ rotamer、φ/ψ Ramachandran basin —— 物理上本就离散。把 torsion 离散化，生成头预测 code 分布，采样后仍用现有 torsion→frame→atom 解码，几何机制完全复用。训练集 mode 在 code 上有清晰峰，温度/top-k 即可采出（比 MultiStateFold 那种"单态偏置预训练模型上事后跨能垒"容易）。
诚实 caveat
  • 采样要探索：少数清晰 mode 用温度/top-k；mode 多且崎岖仍需 PT/离散扩散。训练集 mode 通常较易。
  • torsion 耦合：逐 torsion 独立 categorical 丢相关性；自回归/联合更好，先做独立 bin 验证可行性足够。
  • trunk 目标端到端：冻结 FAPE 训出的 trunk（表示已平均）会削弱条件信息；最好让 trunk 随似然目标一起调。
  • token→结构非保距（MultiStateFold：88.7% token 差异仍可 TM 0.96）：朴素改 logit 逼不出新构象，需真采样。
  • 属改头/从头研究，与当前续训不兼容；但作为"训练集多模可采样性"小实验规模可控。
